# 🎯Project Name:
### Social Event Management


## 📝Description:
This is a modern social event management platform designed to connect people through meaningful community activities and social initiatives.
Users can discover upcoming events, view event details, join events, and manage events they have created. The platform focuses on making community participation simple, organized, and accessible.


## 🚀Using Technologies:

### 💻Frontend-
 - Next.js
 - React
 - TypeScript
 - Tailwind CSS
 - shadcn/ui
 - Lucide React
 - Better Auth

### 🛠️Backend-
- Node.js
- Express.js
- MongoDB
- CORS
- dotenv


## 📌Features: 

1. Authentication
2. Event Management
3. Explore Events
4. Join Events
5. Responsive Design for all device
